How website viewing works

Gleepy is a standalone HTML interface. It displays websites in an embedded frame when the website allows it. Some websites refuse embedding; use “Open in regular browser” when the page is blank or incomplete. HTML cannot override a website’s frame security rules.

No proxy · no traffic masking · no special network permissions

Saved data

Bookmarks, history, shortcuts, and preferences are stored locally in this browser using local storage. They are not synced to other devices.

Import by pasting

About Gleepy

Gleepy 2.0 · a browser-style home page with tabs, search, saved links, and an embedded view where supported. It is not a replacement for Chromium, Edge, or another full web browser.
